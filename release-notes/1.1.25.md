# ScanIndex 1.1.25

- Giảm báo nhầm (false positive) khi tìm file mật: chữ mật "dính hai bên" trong dòng văn bản/tiêu đề dài (trước và sau từ khóa đều còn chữ, dòng ≥4 từ — ví dụ "MỘT SỐ MẶT HẠN CHẾ", "MẶT TRẬN 6 THÁNG ĐẦU NĂM") không còn bị tính là dấu mật; dòng số ký hiệu thật ("Số 15/TB-MẬT") kết thúc bằng từ khóa vẫn nhận như cũ.
- Quét file mật: sửa lỗi xác nhận "Không phải mật" bị sai file khi xác nhận liên tiếp nhiều file trong lúc lượt quét đang chạy. Nguyên nhân: hộp thoại xác nhận làm danh sách nhận thêm/rút bớt dòng giữa chừng, bản trước ghi nhớ "file kế tiếp" bằng số thứ tự dòng nên tự chuyển preview sang nhầm file — lượt xác nhận sau bị "tiêu" vào nhầm file, file định xác nhận vẫn còn trong danh sách.
- Giờ app truy vết file kế bằng đường dẫn file (không đổi khi danh sách xáo trộn) rồi tra lại vị trí mới trên bảng trước khi chuyển preview; lệnh gỡ dòng có thêm lưới an toàn quét toàn bảng nên file đã xác nhận không thể còn nằm lại danh sách vì lỗi lệch dữ liệu nội bộ.
- Bấm Hủy trong hộp thoại xác nhận (hoặc xóa file lỗi do file bị khóa) giờ giữ nguyên file đang xem để thử lại, không tự nhảy sang file khác.
- Bổ sung 9 test tự động cho luồng xác nhận "Không phải mật" liên tiếp (chạy trong lúc danh sách xê dịch, file nhiều dòng, file cuối bảng, Hủy hộp thoại, xóa lỗi, lệch dữ liệu nội bộ).
